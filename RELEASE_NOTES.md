# Rclone Lite 1.0.0

The first public release of Rclone Lite: a free, Spanish-language desktop GUI for rclone on Windows 10 and 11.

## Highlights

- Browse local drives and cloud remotes in a dual-pane explorer.
- Compare folders and see left-only, right-only, different, and matching entries.
- Copy, sync, and move files with dry-run, filters, and 1:N destinations.
- Manage rclone remotes and recurring jobs from a native Windows interface.
- Keep the app in the system tray and receive transfer-completion notifications.
- Install without administrator permissions. The setup includes rclone and the Visual C++ runtime.

## Install

Download `RcloneLite-Setup-1.0.0.exe` below and run it. WinFsp is only required for drive mounts. The installer is unsigned, so Windows SmartScreen may show an unknown-publisher warning.
