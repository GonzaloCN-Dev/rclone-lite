# Rclone Lite 1.3.1

## Cambios

- Se ha eliminado de Ajustes la sección duplicada para configurar credenciales de Google Drive. Ahora se gestionan desde **Remotos**.
- Los avisos de limitación de cuota de Google indican que se revisen las credenciales del remoto en **Remotos**.
- Si intentas cerrar la aplicación con transferencias activas, se te pedirá confirmación para que puedas cancelar el cierre y evitar que se interrumpan por accidente.

## Actualización

Descarga `RcloneLite-Setup-1.3.1.exe` en los archivos adjuntos de esta release e instálalo sobre la versión anterior. Tus trabajos, remotos e historial permanecen en `%APPDATA%\RcloneLite`.

El instalador es x64 para Windows 10/11 y no está firmado, por lo que Windows SmartScreen podría mostrar un aviso de editor desconocido.
